# Геоінформаційне моделювання динаміки земного покриву (колишнє Каховське водосховище, 2021–2025)

Код до кваліфікаційної роботи магістра «Геоінформаційне моделювання просторово-часової динаміки земного покриву на територіях, постраждалих від бойових дій (на прикладі Півдня України), з використанням Google Earth Engine».

## gee/
- `script_v8.js` — основний скрипт Google Earth Engine: ознаки Sentinel-2/1, навчальні мітки (ESA WorldCover, Dynamic World), Random Forest окремо для кожного року, площі та матриці переходів, порівняння берегів, SAR-картування прориву (відносна орбіта 65), пожежі (MCD64A1, FIRMS, dNBR). Експорт у Google Drive.
- `sar_orbit65.js` — окремий скрипт SAR-картування осушення й затоплення (06.06.2023).

## python/
Відтворення рисунків і розрахунків за експортованими з GEE даними. Структура: `data/tables` (CSV), `data/rasters` (GeoTIFF), `figures/`.
1. `trend_check.py` — перевірка трендів, колишня водна зона
2. `charts.py`, `maps.py`, `map31.py`, `map21.py`, `workflow.py` — рисунки
3. `make_validation_points.py` — стратифікована вибірка точок валідації (фіксований seed)
4. `make_validation_sheets.py` — контактні аркуші для сліпої розмітки за знімками надвисокої роздільності

Залежності: numpy, pandas, matplotlib, rasterio, pyproj, pillow, geopandas==0.14.4.
